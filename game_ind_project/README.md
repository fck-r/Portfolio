# Описание проекта

Необходимо провести ссследование мирового рынка компьютерных игр и на основании данных из открытых источников выявить определяющие успешность игры закономерности, что позволит сделать ставку на потенциально популярный продукт и спланировать будущие рекламные кампании.

***Используемые модули и библиотеки:*** pandas, numpy, math, matplotlib, seaborn, scipy, os, re, datetime.

## Описание данных 

- name — название игры;
- platform — платформа;
- year_of_release — год выпуска;
- genre — жанр игры;
- na_sales — продажи в Северной Америке (миллионы проданных копий);
- eu_sales — продажи в Европе (миллионы проданных копий);
- jp_sales — продажи в Японии (миллионы проданных копий);
- other_sales — продажи в других странах (миллионы проданных копий);
- critic_score — оценка критиков (максимум 100);
- user_score — оценка пользователей (максимум 10);
- rating — рейтинг от организации ESRB.

### Итог

Были сформулированы и проверены две статистические гипотезы, а также выделено и описано несколько ключевых факторов, оказывающих влияние на популярность игровых продуктов (в т.ч. описаны портреты пользователей разных регионов), которые необходимо учитывать при планировании рекламных кампаний.
