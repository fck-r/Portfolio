# Tableau

Перед телекоммуникационной компанией, которая оказывает услуги на территории всего СНГ, стоит задача определить текущий уровень потребительской лояльности, или NPS (Net Promoter Score), среди клиентов из России. Необходимо построить дашборд, который представит информацию о текущем уровне NPS среди клиентов и покажет, как этот уровень меняется в зависимости от пользовательских признаков. 

**Ссылка на дашборд:** https://public.tableau.com/views/NPC_telecom/Dashboard?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

## Yandex DataLens

Для благотворительного фонда “Рауль”, который занимается развитием в регионах РФ экосистемы сопровождаемого трудоустройства людей с инвалидностью, людей с опытом сиротства, выпускников адаптированных образовательных программ, требуется создать удобный внутренний интерактивный дашборд, который бы позволял сотрудникам фонда видеть данные о результатах деятельности фонда и отображал динамику и структуру трудоустройств.

**Ссылка на дашборд:** https://datalens.yandex.cloud/qdb1da872gz6f-trudoustroennye-bf-raul
