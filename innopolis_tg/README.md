# Описание проекта

Заказчик исследования хочет увеличить лояльность аудитории бренда путем увеличения количества подписчиков телеграм-канала. В ходе исследования необходимо провести анализ нынешнего состояния телеграм-канала города и выявить наиболее эффективные и точные метрики для еженедельного/ежемесячного анализа работы. 

***Используемые модули и библиотеки:*** pandas, numpy, matplotlib, seaborn, wordcloud, nltk, pymorphy2, gspread, google, re, ast, string.

## Описание данных 

**Таблица innopolistg (записи о постах телеграм-канала):**
- channel - ссылка на телеграмм-канал на котором оставлен пост;
- id - униальный идентификатор поста;
- date - дата поста;
- text - содержание поста;
- views - количество просмотров поста;
- reactions_count - количество реакций, оставленных под постом;
- comments - количество комментариев, оставленных под постом;
- type_attachment - тип вложения поста.

**Таблица comments_innopolistg_061223 (содержание комментариев к постам телеграм-канала):**
- post_id - униальный идентификатор поста, под которым оставлен комментарий;
- date_comment - дата оставления комментария;
- text_comment - содержание комментария.

**Таблица innopolistg_emoji (содержит статистику по каждому эмодзи, примененному в публикациях):**
- index  - номер поста;
- channel - ссылка на телеграмм-канал на котором оставлен пост;
- id - униальный идентификатор поста;
- date - дата поста;
- text - содержание поста;
- views - количество просмотров поста;
- reactions_count - количество реакций, оставленных под постом;
- comments - количество комментариев, оставленных под постом;
- type_attachment - количество комментариев, оставленных под постом;
- reactions - статистики по каждой реакции (эмодзи), оставленной под постом.

### Итог

Был проведен подробный анализ постов в телеграм-канале, оставленных под ними комментариев и реакций. Сами посты кластеризированы на 8 основных тематик, выявлены и проанализированы все (как предоставленные в исходных данных, так и расчетные) метрики для отслеживания динамики состояния канала, даны рекомендации по их повышению.
