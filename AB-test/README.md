# Описание проекта

В компании был проведен A/B-тест с целью тестирования изменений, связанных с внедрением улучшенной рекомендательной системы. Необходимо оценить корректность проведения теста и проанализировать его результаты в плане оценки целесообрзаности внедрения новой системы рекомендаций, ожидаемым эффект от которой выражается в статистически значимом росте основных метрик конверсии в соответствии с техническим заданием.

***Используемые модули и библиотеки:*** pandas, numpy, matplotlib, seaborn, plotly, scipy, statsmodels, os, re, itertools, datetime.

## Описание данных 

**Таблица final_ab_events:**
- user_id — идентификатор пользователя;
- event_dt — дата и время события;
- event_name — тип события;
- details — дополнительные данные о событии, например, для покупок (purchase) в этом поле хранится стоимость покупки в долларах.

**Таблица ab_project_marketing_events:**
- name — название маркетингового события;
- regions — регионы, в которых будет проводиться рекламная кампания;
- start_dt — дата начала кампании;
- finish_dt — дата завершения кампании.

**Таблица Таблица final_ab_new_users:**
- user_id — идентификатор пользователя;
- first_date — дата регистрации;
- region — регион пользователя;
- device — устройство, с которого происходила регистрация.

**Таблица Таблица final_ab_participants:**
- user_id — идентификатор пользователя;
- ab_test — название теста;
- group — группа пользователя.

### Итог

В ходе проверки результатов теста было выявлено нарушением некоторых пунктов технического задания, а также несколько фактов, которые своим влиянием потенциально могли исказить результаты тестирования. И хотя нельзя говорить о полной компроментации проведенного теста, сам тест не достиг целевых показателей, которые подтвердили бы эффективность новой рекомендательной системы.
