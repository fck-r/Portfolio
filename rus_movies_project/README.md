# Описание проекта

Используя портал открытых данных Министерства культуры и данные с сайта “КиноПоиск” необходимо изучить рынок российского кинопроката, выделить тренды. Уделить внимание фильмам, которые получили государственную поддержку и попробовать ответить на вопрос, насколько такие фильмы интересны зрителю. 

***Используемые модули и библиотеки:*** pandas, numpy, matplotlib, seaborn, os.

## Описание данных 

- title — название фильма;
- pu_number — номер прокатного удостоверения;
- show_start_date — дата премьеры фильма;
- type — тип фильма;
- film_studio — студия-производитель;
- production_country — страна-производитель;
- director — режиссёр;
- producer — продюсер;
- age_restriction — возрастная категория;
- refundable_support — объём возвратных средств государственной поддержки;
- nonrefundable_support — объём невозвратных средств государственной поддержки;
- financing_source — источник государственного финансирования;
- budget — общий бюджет фильма;
- ratings — рейтинг фильма на КиноПоиске;
- genres — жанр фильма;
- box_office — сборы в рублях.

### Итог

По итогам проведенного анализа были сформулированы выводы как по всему рынку российского кинопроката в целом, так и отдельно по фильмам, получавшим государственную поддежку. Даны рекомендации по повышению эффективности государственного финансирования отчественного кинематографа
